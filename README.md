# drone-detector

A computer vision project for detecting objects in images using YOLOv8.
Built as a learning project covering the full ML engineering pipeline.

## Setup

```bash
python -m venv .venv
# Windows:
.venv\Scripts\pip install ultralytics
# Linux/Mac:
.venv/bin/pip install ultralytics
```

## Run

```bash
# Windows:
.venv\Scripts\python main.py path/to/image.jpg
# Linux/Mac:
.venv/bin/python main.py path/to/image.jpg
```

Press any key to close the detection window.
